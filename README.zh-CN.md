# Anime2.5DRig

把**已按部件分层**的 PSD 拖进来，就会自动识别五官并绑定骨架，立刻动起来。原本要手工做的网格切分、变形、物理设置全部自动完成。无需安装，所有处理都在浏览器本地完成，图片不会上传到任何服务器。

演示：<https://852wa.github.io/Anime2.5DRig/>

## 快速开始

1. 在本目录起一个本地服务，然后打开 `http://127.0.0.1:8000`：
   - 只需预览：`python -m http.server 8000 --bind 127.0.0.1`
   - 需要 OBS 联动：双击 `start_obs.bat`（等价于 `python obs_server.py --port 8000`）
   - **不要在 `file://` 下开摄像头或麦克风**：MediaPipe 的 `.wasm` / `.binarypb` 会被浏览器 CORS 拦截，追踪起不来。仅拖入 PSD 做静态预览时 `file://` 可用。
2. 点「加载示例 A / 示例 B」先体验，或拖入自己的 PSD。
3. 右侧面板调整表情、朝向、物理；点「保存调整」可存到本浏览器。

界面右上角可切换 **简体中文 / 日本語**，切换不会刷新页面，正在编辑的模型会保留。默认语言是简体中文；
也可以用 `?lang=ja` 直接以日文打开，选择结果会记在浏览器里。

## PSD 要求

- RGB、8bit/通道，最大 128MB，单边不超过 16384px、总计不超过 2400 万像素。
- 每个部件一个独立图层，支持文件夹分组（可识别可见性）。
- 不支持 PSB、组混合模式、调整图层、蒙版效果的完整还原，请把这些效果合并进图像部件。
- 单张插画的自动拆分不在本工具内完成，请先用 see-through 等工具生成分层 PSD。

## 图层命名规范

名字不区分大小写，也支持日文名。常见对应关系：

| 部件 | 可用图层名 |
|---|---|
| 脸 | `face`、`顔` |
| 眼白 | `eyewhite`、`白目` |
| 瞳孔 | `irides`、`瞳`、`黒目` |
| 睫毛 | `eyelash`、`まつ毛` |
| 眉毛 | `eyebrow`、`眉` |
| 闭眼 | `eye_close`、`閉じ目` |
| 张嘴 | `mouth_open`、`開き口` |
| 闭嘴 | `mouth_close`、`閉じ口` |
| 刘海 / 后发 | `front hair` / `back hair`、`前髪` / `後髪` |
| 身体 / 手臂 | `topwear` / `handwear` |
| 饰品 / 眼镜 | `objects` / `eyewear` |

缺少闭眼、闭嘴差分时，会自动生成通用差分；可在「眼睛」「嘴巴」的差分滑杆里微调。
右下角「模型信息 · 诊断」会列出找到和缺失的部件。

## 自动生成嘴（v2.1 / v2.2）

PSD 里只有一张画好的嘴、没有开闭差分时（see-through 之类），旧做法是把这张图纵向拉伸再淡入淡出到通用闭嘴，嘴型永远是同一张、过渡处出双影、い / う / え / お 根本做不出来。

现在改成「量原画 → 参数空间插值 → 每帧重画」：

- **自动生成嘴**滑杆控制开关，0 退回原来的差分切换。原画本身是闭嘴时，闭嘴状态一个像素都不改，只在需要开口时淡入生成的嘴。
- **口型风格**下拉有 6 档：自动判定 / 实测（按原画嘴形绘制）/ 动画标准 / 有唇（偏写实）/ 简洁（平涂）/ Q 版。不合适就换一个。
- **元音 a・i・u・e・o** 五根滑杆（以及摄像头 / 麦克风 / 自动闲聊的驱动）决定嘴形是哪一种，中间态是几何参数的连续插值，不会出现两套唇线叠加。
- **下巴联动**：张嘴时下颚跟着下移、u / o 时脸颊内收。没有这一条，嘴动脸不动，一眼假。
- **用音频文件对口型（唱歌）**：在「摄像头 · 麦克风」里选一个音频文件（建议用人声分离后的 vocal 轨），播放时用 LPC 共振峰估计元音驱动嘴形。**音高补偿**用于修正男女声的共振峰差异。

绘制细节（口腔渐变、舌头只在大开口时出现、牙齿高度随开口变化、侧壁厚度、两端收尖的上唇线）和实现说明见 `MOUTHGEN.md`，
六态示意见 `docs/mouth-styles/*.svg`。

## 编辑与保存

- 表情预设：数字键 `1`～`7`，`0` 清除；再按同一个键可取消。
- 自动动作：待机、眨眼、随机动作、随机口型、头发物理、摄像头 / 鼠标 / 麦克风追踪。
- 「编辑锚点」可在预览上拖动，修正眼睛、嘴巴、脖子等自动识别的基准点。
- 调整按模型保存在浏览器本地；「导出设置 JSON」可带到别的环境，JSON 也能直接拖进预览区加载。
- 支持撤销 / 重做，右上角显示帧率。

## 导出

- 「保存 PNG」输出当前姿势的透明 PNG。
- 「录制」输出 WebM / MP4 视频，可选 3～60 秒、30 / 60fps。
- 背景可选透明 / 绿幕 / 深色。**透明通道只有 WebM（Chrome / Edge）能保留**，MP4 不支持透明。

## OBS 联动

1. 双击 `start_obs.bat`，会启动本地服务并打开编辑页面（需允许摄像头）。
2. OBS 中添加「浏览器」源，URL 填 `http://127.0.0.1:8000/?obs=1`，宽高与 PSD 一致。
3. 编辑页里打开的 PSD、调整、表情、锚点和面部追踪会实时同步到 OBS；OBS 专用画面背景完全透明、不显示操作面板。
4. 端口被占用时可用 `python obs_server.py --port 8001 --open-browser --camera`，并同步修改 OBS 的 URL。

摄像头追踪与麦克风口型只在 https 或 localhost 下可用（浏览器权限限制）。MediaPipe FaceMesh 已随项目附带，离线也能用。

## 已知限制

- 不拆分单张插画，只处理已分层的 PSD。
- 文件夹的可见性会生效，但组混合模式、不透明度继承、特殊混合模式、调整图层、蒙版效果不在支持范围内。
- `file://` 直接打开时解析在主线程进行，无法中途取消；建议用 localhost。
- 设置保存在浏览器 localStorage，隐私模式或容量不足时请改用 JSON 导出。
